# Security policy

Security fixes are accepted for the latest source version.

Please use GitHub's private vulnerability reporting feature when it is available for this repository. If it is not available, open a minimal public issue asking the maintainer to establish a private contact channel; do not include exploit details, credentials, private documents or personal information in that issue.

The application processes untrusted PDF files. Reports involving malformed files should use a minimal synthetic sample that you have permission to share.
