# VF PDF Helper

![VF PDF Helper icon](assets/vf-pdf-helper.png)

VF PDF Helper is a free and open-source Windows application for viewing PDFs and embedded PRC/U3D 3D models, organizing pages, filling forms, adding handwritten signatures, and editing real PDF text layers.

Project home: <https://github.com/FFeederR10/vf-pdf-helper>

## Features

- Open and browse PDF files with zoom, fit-to-width, and page navigation
- Reorder pages by dragging thumbnails in the sidebar
- Insert another PDF with a selectable source page range and insertion position
- Select multiple pages to delete or rotate
- Click a text block to select it, then press Delete or Backspace to remove it
- Drag a selected text block to reposition it
- Double-click existing text for inline editing; press Enter or click elsewhere to save
- Click anywhere in Add Text mode and type directly on the page
- Change font, size, color, bold, italic, and underline from a floating toolbar
- Fill AcroForm text, checkbox, radio, combo-box, and list fields
- Draw handwritten signatures as standard PDF Ink annotations
- Detect PRC and U3D 3D annotations while preserving their embedded 2D posters
- Automatically open the first supported embedded 3D object after a PDF is loaded
- Open PRC and common U3D CLOD mesh models in an interactive 3D window with rotate, pan, zoom, lighting, and wireframe controls
- Decode complete supported U3D triangle geometry in the background by default, with progress, cancellation, and explicitly optional incomplete performance previews
- Undo and redo up to 12 editing operations
- Export through an atomic write and reopen the result for verification
- Open a PDF from the command line, allowing the app to be set as the Windows default PDF viewer

## Requirements

- 64-bit Windows 10 or Windows 11
- An OpenGL 2.1-compatible graphics driver for the built-in 3D viewer
- Python 3.12 when running or building from source

## Run from Source

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Build for Windows

```powershell
.\build.ps1
```

Build outputs:

- `dist\VF PDF Helper\VF PDF Helper.exe`
- `dist\VF-PDF-Helper-windows-x64.zip`

The application uses PyInstaller's `onedir` mode so bundled runtime libraries remain visible and easier to inspect, replace, and rebuild. The ZIP also includes the project license, third-party notices, and corresponding-source information.

## Text and Font Behavior

Direct text editing requires a real PDF text layer. Scans, screenshots, and CAD drawings whose text has been converted to outlines do not contain selectable text. Those documents can still be viewed, reorganized, signed, and annotated with new text.

VF PDF Helper does not redistribute Windows font files. Before embedding an installed system font into an editable PDF, the application checks the font's OpenType/TrueType embedding-permission flags. The application icon is a project-owned bitmap generated by `scripts/make_icon.py`.

## PDF Forms and Signatures

Fill Form mode preserves supported AcroForm fields as interactive form objects after export. Signature Pen mode creates PDF Ink annotations rather than flattening the entire page into an image.

## 3D PDF Support

3D PDFs store models in `PRC` or `U3D` annotation streams. VF PDF Helper detects both formats and continues to render the author-provided 2D poster on the normal PDF page.

The first supported PRC or U3D annotation opens automatically when a PDF is loaded; **3D** on the toolbar reopens it. Left-drag rotates the model, Shift+left-drag or right-drag pans it, and the mouse wheel zooms. The viewer also provides lighting, wireframe, and reset controls.

The U3D decoder supports triangle geometry stored in CLOD base-mesh blocks, including compressed multi-part assemblies and their model-node transforms. **Complete** is the default and loads every supported triangle, even when this takes substantially longer. **High (incomplete)** and **Fast (incomplete)** are opt-in previews for users who explicitly prefer performance; transformed outline proxies show the location of parts omitted only in those modes. Complete mode refuses to display a model rather than silently truncate it when the file uses unsupported progressive refinement or exceeds the 10,000,000 expanded-face complete-render safety limit. Point-only and line-only models are also not yet decoded; Adobe Acrobat or Reader remains an optional fallback for those cases.

Only activate 3D content from documents you trust. VF PDF Helper parses embedded model data locally and applies stream, block, element, nesting, and preview-size limits before rendering.
