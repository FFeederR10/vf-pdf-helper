# Contributing

Thanks for helping improve VF PDF Helper.

1. Open an issue for substantial changes so the design can be discussed first.
2. Create a focused branch and include tests for behavior changes.
3. Run `.\.venv\Scripts\python.exe -m pytest -q` before submitting a pull request.
4. Do not commit PDF documents unless you created them specifically as redistributable fixtures and documented their license.
5. Do not commit credentials, Windows font files, build output or generated user data.

Unless explicitly stated otherwise, contributions submitted to this repository are licensed under the repository's GNU AGPL v3 license. Contributors must have the right to submit their code and assets under those terms.
